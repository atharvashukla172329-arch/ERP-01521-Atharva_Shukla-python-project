🚗 Vehicle Rental Management System

📌 Project Overview

The Vehicle Rental Management System is a Python-based console application developed to manage vehicle rentals efficiently. It allows users to add vehicles, rent vehicles to customers, return rented vehicles, and check vehicle availability.

The system automatically calculates rental bills and provides a 10% discount for rentals of 7 or more days.

🎯 Project Objectives

- Manage vehicle records.
- Add new vehicles.
- Rent available vehicles to customers.
- Return rented vehicles.
- Calculate rental bills automatically.
- Save vehicle information permanently using file handling.

🛠️ Technologies Used

- Programming Language: Python 3
- Concepts: Object-Oriented Programming (OOP), Lists, Dictionaries, File Handling
- Storage: JSON file ("vehicles.txt")

⚙️ Features

1. Add Vehicle
2. Rent Vehicle
3. Return Vehicle
4. Check Vehicle Availability
5. Automatic Bill Calculation
6. 10% Discount for 7 or More Days
7. Save and Load Vehicle Records

💰 Billing Calculation

Formula:

Total Bill = Daily Rate × Number of Days

A 10% discount is applied when the rental period is 7 days or more.

Example:

- Daily Rate = ₹1,500
- Rental Duration = 7 Days
- Total Amount = ₹10,500
- Discount = ₹1,050
- Final Bill = ₹9,450
